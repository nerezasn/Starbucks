## 🎨 Design

This project was developed based on an existing Figma design.

[Figma Design Reference](https://www.figma.com/design/4Tuuje39eQPmlKOfa9lwKU/StarBucks----Copy-?node-id=43-73&t=Fz1GmHaiWwZAnsoJ-0)

The design was used as a reference for educational and portfolio purposes.  
All front-end implementation was built by me using HTML and CSS.

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Responsive Design
- SVG Sprite Icons

## 📌 Planned Improvements

- Complete the mobile and tablet versions
- Add a functional slider/carousel to the Products section
- Improve responsiveness across different screen sizes
- Add JavaScript interactions
- Improve accessibility

## 🎯 Purpose

This project was created to practice building a complete landing page from a Figma design and to strengthen my skills in HTML, CSS Grid, Flexbox, responsive layouts, reusable components, and SVG sprites.
